# Hogwarts Puzzle — The Enchanted Corridor

Unofficial fan-made browser puzzle prototype inspired by the magical-school atmosphere of Harry Potter. No official logos, character art, film stills, or licensed assets are used.

## Gameplay

Rotate rune tiles to connect the wand spark on the left to the hidden door on the right. Connected tiles glow blue.

- Click a tile to rotate it 90°.
- **Lumos** solves one route tile at a House Points cost.
- **Revelio** briefly reveals the intended route.
- **Reparo** reshuffles the board.
- Every new game generates a different solvable path.
- Moves, timer, progress, House Points, sound cues, and win scoring are included.

## Run locally

Open `index.html` in any modern browser. No build step, package manager, backend, or API key is required.

## Deploy

This is a fully static, self-contained page and is ready for GitHub Pages, Netlify, Cloudflare Pages, or Vercel static hosting.
